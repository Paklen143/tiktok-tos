Kebijakan Privasi (Privacy Policy)

Terakhir diperbarui: 7 Oktober 2026

1. Informasi yang Kami Kumpulkan

Aplikasi dan sistem otomasi Paklen Finance (Raspberry) TIDAK mengumpulkan, menyimpan, atau menjual data pribadi sensitif milik penonton atau pengguna akhir.

2. Penggunaan API Pihak Ketiga

Aplikasi ini berinteraksi dengan API resmi pihak ketiga (TikTok Developer API, Instagram Graph API, YouTube Data API) semata-mata untuk mengunggah konten video yang telah dibuat oleh pemilik akun. Token autentikasi disimpan secara lokal dan aman di server privat pengembang.

3. Keamanan Data

Kami menerapkan standar perlindungan ketat pada kredensial pengembang. Tidak ada data pihak ketiga yang dibagikan kepada entitas luar atau diperjualbelikan untuk tujuan periklanan tanpa izin.

4. Cookie & Pelacakan

Halaman statis ini tidak menggunakan cookie pelacak pihak ketiga atau alat analitik invasif.

5. Perubahan Kebijakan

Kami dapat memperbarui Kebijakan Privasi ini dari waktu ke waktu jika diperlukan oleh regulasi platform terkait. Perubahan akan langsung tercermin pada halaman ini.
